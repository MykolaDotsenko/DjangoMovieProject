# Third-party software

MovieShelf does not bundle third-party movie posters, celebrity photographs, or other
third-party demo media. The included demo fixture uses fictional records and empty image
fields so the repository can be evaluated without redistributing media assets.

The browser UI references the following external libraries from their public CDNs:

- Bootstrap 5.3.8 — see the Bootstrap project for its license.
- Font Awesome Free 6.7.2 — see the Font Awesome project for the licenses applying to
  its icons, fonts, and code.

Python dependencies are installed from PyPI and remain subject to their respective
upstream licenses.

The repository's own source code is covered by the root LICENSE file.
